# FirstClaudeTest

Einfache statische Webseite (HTML/CSS/JS, kein Build-Tooling).

## Struktur

```
index.html      Einstiegspunkt der Seite
css/style.css   Styles
js/main.js      Skripte
assets/         Bilder und weitere statische Dateien
```

## Lokal ausführen

Die `index.html` direkt im Browser öffnen, oder mit einem lokalen Server starten, z. B.:

```
npx serve .
```
